# AI Roles

## Human / Tech Lead
Never fully delegate:
- product goal
- requirements approval
- architecture ownership
- security/risk acceptance
- final merge/release decision
- learning that I need for my own engineering competence

## ChatGPT
Best used for:
- concept learning
- Socratic questioning
- architecture critique
- trade-off analysis
- research and synthesis
- requirements review
- debugging explanation
- independent review

## Claude
Best used for:
- bounded implementation tasks
- refactoring proposals
- generating tests from explicit criteria
- alternative implementation approaches
- independent review

## Important rule
Model assignments are not permanent. In some tasks ChatGPT implements and Claude reviews. In others the reverse happens. The purpose is to demonstrate orchestration and verification, not loyalty to a specific model.

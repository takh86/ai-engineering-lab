# AI Use Disclosure Standard

Every lab project should include a concise disclosure answering four questions.

## 1. What did I own?
Describe the problem framing, requirements, architecture decisions, trade-offs, and final review performed personally.

## 2. What did AI do?
Name the task categories, not every prompt. Example: generated initial DTO/test boilerplate, proposed edge cases, reviewed a pull request.

## 3. How was output verified?
List objective checks: tests, static analysis, manual review, integration checks, security checks, or measured evals.

## 4. What went wrong?
Document at least one meaningful defect, weak assumption, or correction when one occurred. A perfect AI history is less credible and less educational than a verified correction loop.

Do not publish private chat histories, secrets, proprietary context, or unnecessary raw prompts.

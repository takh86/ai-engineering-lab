# تبصرة — حزمة إعادة بناء الشعار المتجهي V1

هذه إعادة بناء من الصور المرسلة، وليست الملفات الأصلية للمصمم. تحتفظ باتجاه الرمز، ترتيب الشرائح، الكتابة العربية وتوزيع الألوان. شكل الحروف والانحناءات والتدرجات تقريبي بسبب ضبابية المرجع. راجع المعاينة قبل اعتمادها بديلًا نهائيًا.

## ملفات SVG
- tabsira-symbol.svg: الرمز وحده، بخلفية شفافة.
- tabsira-symbol-mono.svg: الرمز بلون واحد.
- tabsira-logo-light.svg: كتابة زرقاء للاستخدام على الخلفيات الفاتحة، بخلفية شفافة.
- tabsira-logo-dark.svg: كتابة بيضاء للاستخدام على الخلفيات الداكنة، بخلفية شفافة؛ استخدم هذه النسخة في رأس التطبيق.
- tabsira-logo-mono.svg: الشعار كاملًا بلون أزرق واحد.
- tabsira-logo-white.svg: الشعار كاملًا باللون الأبيض.
- tabsira-logo-dark-background.svg: نسخة معاينة بخلفية صريحة #0B3B8F.
- tabsira-app-icon.svg: أيقونة التطبيق بخلفية #0B3B8F وزوايا مستديرة.

كل الرسوم والكتابة مسارات متجهة. لا صور نقطية مضمنة، ولا ملفات خطوط مطلوبة، ولا موارد خارجية.

## الألوان
الكتابة والخلفية الأساسية: #0B3B8F. الأزرق الرئيسي: #1456C5. اللون الليموني المرجعي: #B7E445.
تدرجات الرمز أعيد بناؤها بصريًا: السماوي #22C5F3 / #13D4E8 / #18C6EF؛ الأزرق #1456C5 / #039CF3 / #0854AC / #0769ED؛ الليموني #CBF845 إلى #9BDA20. هذه الدرجات تقديرية وليست قياسات موثقة من أصل متجهي.

## PNG
أيقونة التطبيق متاحة بمقاسات 16، 32، 48، 128، 192، 512، 1024 بكسل. الشعار الفاتح والداكن بعرض 1536 بكسل. الرمز الشفاف بعرض 1024 بكسل.

## التحقق
تم التحقق من صلاحية XML لكل SVG، وعدم وجود عناصر image أو text أو مراجع خارجية. تم تصدير النسخ باستخدام Inkscape ومراجعة المعاينة. الخطوط مستبدلة بمسارات، وتفاصيل التدرج قابلة للتحرير.

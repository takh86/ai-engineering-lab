# Third-party notices — built-in adult-sites list

The file `rulesets/base_adult.json` shipped in the extension package is generated from the list snapshot
`data/base-list/adult-domains.txt.gz` (714,093 domain names, retrieved 2026-10-02).
Domain names are facts, but the lists they come from are curated works, so the licences of the sources are reproduced below.
Composition rule, input hashes and per-source counts: `data/base-list/PROVENANCE.json` and `data/base-list/README.md`.

Sources that contribute to the shipped list:

1. **The Block List Project** — `porn.txt` — https://github.com/blocklistproject/Lists — The Unlicense.
2. **ShadowWhisperer BlockLists** — `Lists/Adult` — https://github.com/ShadowWhisperer/BlockLists — The Unlicense.
3. **Sinfonietta hostfiles** — `pornography-hosts` — https://github.com/Sinfonietta/hostfiles — MIT.

Sources that were examined and are **not** included (entries traceable only to them were removed; nothing was copied from them):

- HaGeZi `dns-blocklists` (nsfw) — GNU GPL-3.0 (copyleft; not compatible with the project's undecided licence strategy).
- zachlagden `Pi-hole-Optimized-Blocklists` (nsfw) — no licence file found.
- Clefspeare13 `pornhosts` — licence stated in a header only; upstream LICENSE could not be retrieved.

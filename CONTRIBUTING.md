# Contributing to My AI Engineering Lab

This repository is primarily a personal engineering portfolio and learning system.

The working standard is:

1. Understand before generating.
2. Specify before implementing.
3. Keep AI tasks bounded.
4. Verify with tests and tools.
5. Review critical code manually.
6. Record important mistakes and corrections.
7. Do not merge code that cannot be explained.

External feedback and issue reports are welcome when the repository is public.
